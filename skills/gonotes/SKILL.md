# goNotes

- Используй инструменты goNotes MCP для всех операций с личными заметками.
- Считай слово «заметки» без уточнений запросом списка через `notes_list`.
- Перед изменением существующей заметки найди ее через `notes_list` или `note_get`; не угадывай ID.
- Для дополнения заметки предпочитай `note_update` с `append_content`.
- Если goNotes MCP недоступен, сообщи об этом и не заменяй его локальными файлами.
- Перед `notes_delete_permanently` получи явное подтверждение пользователя.
